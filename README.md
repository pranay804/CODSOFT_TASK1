# CODSOFT AI Internship – Task 1

## Rule-Based Chatbot Using Python

This project is developed as part of the CodSoft Artificial Intelligence Internship.

### Project Description
A simple rule-based chatbot developed using Python. The chatbot responds to user messages using predefined rules and if-else conditions.

### Features
- Responds to greetings
- Answers basic questions
- Provides current date and time
- Gives information about Python
- Handles unknown questions
- Exits when the user types "bye"

### Technologies Used
- Python
- Visual Studio Code

### How to Run
1. Install Python.
2. Download `chatbot.py`.
3. Open the project folder in VS Code.
4. Run `py chatbot.py` in the terminal.
5. Start chatting with the bot.
